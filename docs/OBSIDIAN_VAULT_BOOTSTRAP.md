# Obsidian Vault bootstrap

`vault-bootstrap/`은 Learning MCP를 현재 LLM Wiki형 Obsidian Vault에 연결할 때 복사하는 비파괴 overlay다.

- `HOME.md`: 사용자의 단일 시작점
- `dev/wiki/learning/README.md`: 최소 학습 루프
- `dev/wiki/learning-dashboard.md`: Dataview 기반 리뷰·일지·개념 대시보드

기존 `raw/`, 일간 기록, 프로젝트 노트는 이동하거나 삭제하지 않는다. Vault에 적용하려면 `vault-bootstrap/` 디렉터리의 **내용**을 Vault 루트에 복사한다.
